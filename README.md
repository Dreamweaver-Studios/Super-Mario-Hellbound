# Super Mario Hellbound

A run-and-gun platformer by **Dreamweaver Studios** for the Game Boy Advance. Mario blasts his way through 16 levels across four worlds. Collect coins and power-ups along the way.

## Play

Open the "gba" folder to find the "sm-hellbound.gba" ROM file.
